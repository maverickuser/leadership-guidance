# Security

If you find a way this tool could leak a cookie, send requests to another site, or write
files outside its archive folder, please open a
[private security advisory](https://github.com/maverickuser/leadership-guidance/security/advisories/new)
instead of a public issue. Don't include a real cookie value in the report.

If you ever commit a cookie by mistake: sign out of the site (which invalidates the session),
remove the value from git history, and sign in again to get a new cookie.
